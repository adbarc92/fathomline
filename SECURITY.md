# Security policy

Please report a vulnerability privately, through GitHub's private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for
it.

Include what you found, how to reproduce it, and the commit or image tag it affects. You'll get an
acknowledgement, and the fix and any advisory will be coordinated with you before anything is made
public.

Only the latest commit on `main` and the most recent published image are supported.
